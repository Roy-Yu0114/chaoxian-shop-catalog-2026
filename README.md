# 潮鮮蔬店｜公開食材商品目錄及每日菜單

本網站為潮鮮蔬店商品瀏覽、每日供餐菜單及採購需求清單的公開靜態入口，採原商城的 style.css 樣式與商品卡片版型。

## 功能
- 2026年每月供餐行事曆：依日期查詢每日菜色、下載整月菜單。
- 生鮮蔬菜、冷凍肉品、水產、加工調理、豆腐、食品、耗材等全分類商品目錄。
- 商品售價依正式規則「最近有效已入庫進貨單位成本加25%」所產生的公開價目快照。
- 依商品料號搜尋、分類、排序、採購需求數量、下載CSV與複製清單。
- 自適應手機與桌機。

## 服務邊界（不得誤導客戶）

本網站使用 GitHub Pages 公開靜態檔案，**不提供PHP會員登入、真正訂單寫入、付款或多會員共享訂單庫**。下載／複製的採購需求需由業務窗口或後續正式PHP會員訂購系統確認。不得稱已完成正式訂單，未連線到NAS正式資料庫。

本repo只含公開白名單欄位：SKU、商品名稱、規格、販售單位、分類、商城售價、公開原有商品圖片、讀取日期與供餐菜色。**不包含成本、供應商、客戶、個資、原始SQLite、帳密、NAS位置或簽核文件**。程式來源與測試報告只保留於本機，不上傳至public GitHub。

商品價格為2026-11-11的最近有效入庫成本×1.25快照。未有可核實最新進價或箱包單位不一致之SKU不提供自動報價。

## 正式商務上線的必要條件

在正式PHP HTTPS會員服務和已驗收的私有訂單資料庫上線之前，不應把本目錄的本機採購清單視為正式訂單。需依序完成六家客戶正式帳號UAT、價格與庫存準確度、運送批次與截止時間、中央廚房配方核准、後台訂單對帳及安全驗收。
